# PuttingCaddy (퍼팅캐디)

골프 퍼팅 거리 측정 앱 (Flutter + Android ARCore)

## ⚠️ 버전 노트

- **Basic 모델**: 현재 버전이 Basic 모델의 **최종 버전**입니다.
- **향후 계획**: Pro 모드와 합칠 예정이며, 이후 Basic/Pro가 통합된 단일 앱으로 발전합니다.
- **통합 계획서**: [docs/PRO_MODE_INTEGRATION_PLAN.md](docs/PRO_MODE_INTEGRATION_PLAN.md) (Play Billing, 상품 구조, 화면 흐름 포함)
